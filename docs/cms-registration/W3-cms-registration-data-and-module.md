## OBSERVED: inputs and the 31 SP columns consumed

A column listed below may be absent from the actual result without a schema error because `get()` returns `None` (`src/fcm_intake/legacy/CMS.py:131-147`).

## INFERRED: integration, layout recommendation, and tests
