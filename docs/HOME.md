# FCM_Structured documentation

This vault is the FCM_Structured documentation set.

- [[INSTRUCTIONS]] — live task list and item ID rules.
- [[completed]] — archive of finished items.

## Conventions

Item IDs are `FCM-1.1-NN`, permanent, and never renumbered. Finished items move to `completed.md`; see [[INSTRUCTIONS]] for the authoritative rules.

The repository root also holds `AGENTS.md` (the AI entry point), outside this vault.

Sample files in this folder are excluded from search and graph view because they contain sensitive material.
